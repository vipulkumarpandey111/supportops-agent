# Cloudnest Feature Request Handling

## How Feature Requests Are Triaged
Feature requests are not resolved by support directly. Support should
acknowledge the request, log it with the product team via the internal
feedback tracker, and let the customer know there's no committed timeline.

## Frequently Requested Features (for context, not commitments)
Dark mode, selective folder sync on mobile, and a public API are the most
requested features as of the last product review. Support agents should
never promise a release date for any of these.

## Beta Program
Customers can opt into the Cloudnest Beta program from Account Settings to
get early access to experimental features. Beta features are unsupported
and may be unstable — set this expectation clearly if a customer asks about
joining.
